## 🚀 Step 1: How to Deploy for ₹0 (GitHub Pages)

1. Log into your GitHub account and create a new public repository named `elektron-circuits`.
2. Upload the `index.html` file into the root of the repository.
3. Go to **Settings** -> **Pages** in your repository.
4. Under **Source**, select `main` branch and `/root` folder, then click **Save**.
5. Within 60 seconds, your site will be live at: `https://<your-github-username>.github.io/elektron-circuits/`
